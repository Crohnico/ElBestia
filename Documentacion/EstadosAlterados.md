# Estados alterados

## Opuestos

Estos opuestos se usan por perks como `Backtalker`, que invierten los estados que recibe el campeon.

| Estado recibido | Se convierte en |
| --- | --- |
| Regeneration | Bleed |
| Bleed | Regeneration |
| Thorns | Caltrops |
| Caltrops | Thorns |
| Weakened | Empowered |
| Empowered | Weakened |
| Vulnerable | Fortified |
| Fortified | Vulnerable |
| Haste | Slow |
| Slow | Haste |
| Burn | FireFortified |
| FireFortified | Burn |
| Drowning | WaterFortified |
| WaterFortified | Drowning |
| Shock | ElectricityFortified |
| ElectricityFortified | Shock |
| Poison | PoisonFortified |
| PoisonFortified | Poison |
| Crush | EarthFortified |
| EarthFortified | Crush |
| WindShear | AirFortified |
| AirFortified | WindShear |
| Splinter | WoodFortified |
| WoodFortified | Splinter |
| LifeSteal | Recoil |
| Recoil | LifeSteal |
| Counterattack | Dizzle |
| Dizzle | Counterattack |

Todos los estados alterados jugables tienen opuesto definido. `None` queda fuera de la tabla.
